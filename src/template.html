Fall-Klassifizierung

Notiz schreiben oder die ganze Kundennachricht einfügen – passende Klassifizierungen erscheinen sofort.

Gelernte Fälle können in diesem Browser nicht (mehr) gespeichert werden – der Browser erlaubt es nicht oder der Speicher ist voll. Neu gelernte Fälle gehen beim Schliessen verloren. Abhilfe: unter „Gelernte Fälle“ mit „Importierte löschen“ Platz schaffen (von Hand gelernte Fälle vorher exportieren).

Beispiele:
Alt+1…3 kopiert einen Vorschlag · Esc leert das Feld · Code eintippen (z.B. 50410) zeigt ihn direkt

Gelernte Fälle

Wenn Text im Feld steht und du einen Code kopierst (Vorschlag, Suche oder Liste), merkt sich das Tool diesen Fall. Ähnliche Texte bekommen danach diesen Code vorgeschlagen. Gespeichert wird nur der bereinigte Text (ohne Anrede, Signatur, E-Mail-Adressen, Telefon-, Konto- und andere Nummern) – nur in diesem Browser. „Exportieren“ speichert nur die von Hand gelernten Fälle, nicht die importierten.

Fälle importieren und testen

Frühere, erledigte Fälle aus Excel oder CSV laden (z.B. ein Export aus dem CRM): eine Spalte mit dem Text (Notiz oder Kundennachricht) und eine Spalte mit der Klassifizierung. Damit kann das Tool seine Genauigkeit an echten Fällen messen und die Fälle auf einmal lernen. Am besten mindestens 200 Fälle, mit mehreren Fällen pro Klassifizierung. Alles passiert in diesem Browser – es wird nichts gesendet.

Für jede Spalte wählen: Text (auch mehrere, z.B. Betreff und Beschreibung) und genau eine Spalte Klassifizierung (Code, z.B. 50410, oder Bezeichnung). Spalten mit Namen, E-Mail-Adressen oder Nummern nicht als Text wählen.
