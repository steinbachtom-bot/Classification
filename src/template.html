Gelernte Fälle

Wenn Text im Feld steht und du einen Code kopierst (Vorschlag, Suche oder Liste), merkt sich das Tool diesen Fall. Ähnliche Texte bekommen danach diesen Code vorgeschlagen. Gespeichert wird nur der bereinigte Text (ohne Anrede, Signatur, E-Mail-Adressen, Telefonnummern und Nummern) – nur in diesem Browser.

Gelernte Fälle können hier nicht (mehr) dauerhaft gespeichert werden – der Browser erlaubt es nicht oder der Speicher ist voll. Neue Fälle gehen beim Schliessen verloren. Bitte exportieren oder importierte Fälle löschen.

Fälle importieren und testen

Frühere Fälle aus Excel oder CSV laden: eine Spalte mit dem Text (Notiz oder Kundennachricht) und eine Spalte mit der Klassifizierung. Damit kann das Tool seine Genauigkeit an echten Fällen messen und die Fälle auf einmal lernen. Alles passiert in diesem Browser – es wird nichts gesendet.

Für jede Spalte wählen: Text (auch mehrere, z.B. Betreff und Beschreibung) und genau eine Spalte Klassifizierung (Code, z.B. 50410, oder Bezeichnung).
